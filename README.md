# appcast

Sparkle appcast.xml hosting for macOS apps via GitHub Pages.

## Structure

```
├── snapocr/
│   └── appcast.xml
└── (future apps)/
    └── appcast.xml
```

## Usage

Each app has its own subdirectory containing an `appcast.xml` file.
The appcast files are generated by Sparkle's `generate_appcast` tool and deployed via CI/CD.

DMG files are hosted on each app's GitHub Releases, not in this repository.
